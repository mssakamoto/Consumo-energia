Primeiro projeto: Cálculo do consumo de energia

Este programa calcula o consumo de energia de equipamentos pelo fornecimento de dados da potência em Watts (W) e tempo de uso em horas
Em adição o programa fornece o valor estimado da conta de energia utilizando parâmetros de custo unitario (R$/KWH) e o consumo KWH
Liguagem usada: PYTHON
